# Модель цены биткоина

Интерактивная страница: три слоя, четыре ползунка, пять критериев опровержения.

**Открыть модель →** https://neokrasav4ik.github.io/btc-model/

**English version →** https://neokrasav4ik.github.io/btc-model/en.html

## Что это

Модель раскладывает цену биткоина на три независимых слоя, перемножаемых друг на друга:

1. **Степенной закон** от возраста сети — управляет десятилетиями.
2. **Насыщение** по предельному числу владельцев — определяет, чем всё закончится.
3. **Халвинг-циклы** с раздельным затуханием верха и низа — четырёхлетние волны внутри.

Ползунки не подбирают желаемое число. Они переключают гипотезу о том, что произошло с рынком в последнем цикле: было ли исчезновение эйфории необратимой переменой или стечением обстоятельств. Страница показывает, во что обходится каждый ответ, и перечисляет, что должно случиться, чтобы модель пришлось выбросить.

## Данные

194 помесячных наблюдения с июля 2010 по начало августа 2026 года, приблизительные закрытия месяца из публичных источников. Ряд лежит в исходнике страницы открытым текстом, массив `OBS`.

Показатель Меткалфа β = 1.897 взят из внешней работы, а не подогнан: счётчик промахов на странице показывает, что происходит с качеством описания при его сдвиге.

## Как запустить

Страница полностью статична и работает без интернета. Достаточно открыть `index.html` (или `en.html`) в браузере — сборки, сервера и установки зависимостей не требуется.

## Зависимости

- [Chart.js](https://www.chartjs.org) 4.4.1 (MIT) — отрисовка, файл `chart.umd.js`
- [IBM Plex](https://github.com/IBM/plex) (SIL OFL 1.1) — шрифты, папка `fonts/`

Обе включены локально. Внешних запросов страница не делает.
